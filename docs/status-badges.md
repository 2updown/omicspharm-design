# 배지 색 규칙 · 상태값 정리

2026-10-27 정리. 웹 프로토타입과 Figma 모두 이 규칙을 따릅니다. 배지는 DS `badge_basic` 컴포넌트만 씁니다.

## 1. 배지 타입

| 쓰임 | DS 타입 | 예 |
|---|---|---|
| 큰 카테고리 | **outline** (테두리 + 글자, 배경 없음) | 단백체 분석, 대사체 분석, 매칭 추천 |
| 단계·상태 | **tertiary** (연한 배경 + 진한 글자, 테두리 없음) | 의뢰접수, 견적 협의, 답변대기 |
| 긍정 결과 (선정·확정·인증) | **fill** (진한 배경 + 흰 글자) | 선정, 최종 확인, 인증 완료 |

- 공통 모양: 높이 22, 좌우 8, 모서리 8, 12px Medium.
- fill은 꼭 눈에 띄어야 하는 결과에만 씁니다. 목록 한 줄에 fill이 여러 개 생기지 않게 합니다.

## 2. 색 규칙

| 색 | 의미 | tertiary 값 (배경 / 글자) |
|---|---|---|
| 파랑 | 진행 중 | #D7EBFF (Blue/100) / #0065F4 |
| 주황 | 확인·처리가 필요한 대기 (보는 사람이 해야 할 일) | #FFECD2 (Orange/100) / #FD4900 |
| 회색 | 완료·종료·임시 | #F5F5F5 (Gray/100) / #525252 |
| 빨강 | 거절·삭제·반려 | #FFE1E1 (Red/100) / #F00011 |
| 청록 (fill) | 선정·확정·인증 완료 | #009788 / #FFFFFF |
| 청록 (outline) | 카테고리 | 테두리·글자 #009788 |

- 같은 상태라도 **보는 사람이 처리해야 하면 주황**, 다른 사람을 기다리면 파랑이나 회색입니다.
- 예외: 컨설턴트 화면의 '수정 요청 · 변경 확인 요청'은 분석파트너 응답을 기다리는 상태지만, 늦어지면 컨설턴트가 챙겨야 해서 주황으로 둡니다. 상담의 '답변대기'도 같은 이유로 모든 사람에게 주황입니다.

## 3. 프로젝트 단계

| 단계 | 클라이언트 | 컨설턴트 | 분석파트너 |
|---|---|---|---|
| 의뢰접수 | 파랑 | **주황** (승인 필요) | — |
| 의뢰승인 / 의뢰확인 | 파랑 (의뢰승인) | 파랑 (의뢰확인) | — |
| 견적 확인 / 견적 협의 | **주황** (견적 확인) | 파랑 (견적 협의) | — |
| 견적 요청 | — | — | **주황** |
| 계약 진행 중 | 파랑 | 파랑 | 파랑 |
| 분석 진행 중 | 파랑 | 파랑 | 파랑 |
| 보고서 등록 | — | 파랑 | 파랑 |
| 보고서 검토 | **주황** (최종 확인 필요) | 파랑 | 파랑 |
| 프로젝트 완료 | 회색 | 회색 | 회색 |
| 삭제 | — | 빨강 | — |
| 임시저장 (제출 전) | 회색 | — | — |

- 단계 이름은 요구사항정의서 시트 기준입니다 (`flow.js` ADMIN_STAGES · CLIENT_STEPS, `mypage.js` P_STAGES).

## 4. 견적 상태

**분석파트너 (견적관리)**

| 상태 | 색 |
|---|---|
| 작성 대기 · 임시저장 · 수정 요청 · 변경 확인 요청 | 주황 |
| 제출 완료 · 클라이언트 검토 중 | 파랑 |
| 선정 | 청록 fill |
| 미선정 · 거절 | 회색 |

**컨설턴트 (의뢰 상세 > 견적서 확인)**

| 상태 | 색 |
|---|---|
| 작성 대기 · 임시저장 · 전달 안 함 · 미선정 | 회색 |
| 제출 완료 · 클라이언트 검토 중 | 파랑 |
| 수정 요청 · 변경 확인 요청 | 주황 |
| 거절 | 빨강 |
| 선정 | 청록 fill |

**클라이언트 견적 차수 (1차·2차…)**: 최신 견적 '확인 대기·최신' 주황, 확정 후 '최종 확인' 청록 fill.

## 7. 인증 · 서류

**분석파트너 인증 (컨설턴트 > 분석파트너 관리)**

| 상태 | 색 |
|---|---|
| 미제출 · 검토 대기 | 회색 |
| 인증 검토 | 파랑 |
| 재제출 요청 | 빨강 |
| 인증 완료 | 청록 fill |

**사업자등록증 (컨설턴트 > 의뢰 상세)**

| 상태 | 색 |
|---|---|
| 확인 전 · 재제출 | 주황 |
| 확인 완료 | 청록 fill |
| 미제출 · 재제출 요청 | 빨강 |

- GNB 프로필·내 정보 관리의 '인증 / 미인증' 칩(`op-vchip`, 인증 아이콘 포함)은 배지와 별개 컴포넌트로 둡니다.
