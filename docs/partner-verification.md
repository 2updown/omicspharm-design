# 분석파트너 인증 · 이메일 인증 규칙 (핸드오프)

프로토타입(`mypage-verify.html` 등)에 반영된 화면 동작의 기준 규칙입니다. 화면에는 결과만 보이므로, 상태가 바뀌는 시점과 컨설턴트 쪽 처리는 이 문서를 기준으로 구현합니다.
작성 2026-10-14 · 미정 항목은 맨 아래에 따로 적었습니다.

## 1. 공통 원칙

- 로그인은 이메일 인증 전에도 열어 둡니다. 가입 단계에 인증 코드 확인은 넣지 않습니다.
- 이메일 인증 전에는 아래 2절의 기능만 막습니다.
- 분석파트너 인증 기준은 **기관 정보 및 사업자등록증**입니다. 컨설턴트가 확인합니다.
- 인증된 분석파트너는 모두 똑같이 견적서를 작성할 수 있습니다.
- 분석 서비스 정보는 선택이며 인증 조건이 아닙니다. 견적서를 보낸 뒤 컨설턴트가 확인하면서 입력을 요청합니다(8절).
- AI 추천 분석파트너는 컨설턴트만 쓰는 내부 도구입니다.

## 2. 이메일 인증 전 제한

| 구분 | 클라이언트 | 분석파트너 | 컨설턴트 |
|---|---|---|---|
| 로그인 | 가능 | 가능 | 대상 아님 |
| 막히는 것 | 프로젝트 의뢰 | 인증 검토 시작 | – |
| 막히는 방식 | [프로젝트 의뢰]를 누르면 안내 토스트. 의뢰 화면에 바로 들어가도 토스트 후 이전 화면으로 이동 | 기관 정보·사업자등록증 입력과 저장은 가능. 검토는 이메일 인증 후 시작('검토 대기') | – |
| 결과적으로 막히는 것 | – | 파트너 인증 → 견적서 작성·제출, 비공개 프로젝트 열람 | – |
| 그대로 되는 것 | 프로젝트 찾기 열람, 문의하기, 마이페이지 | 공개 프로젝트 열람, 문의하기, 마이페이지, 기관 정보·사업자등록증·분석 서비스 입력 | – |

안내 문구
- 클라이언트 의뢰 차단: "이메일 인증 후 이용할 수 있습니다. 가입하신 메일함에서 인증 메일을 확인해주세요."
- 인증 메일 재발송: "인증 메일을 다시 보냈습니다. 메일함을 확인해 주세요."

이메일 미인증 표시 위치

| 위치 | 클라이언트 | 분석파트너 |
|---|---|---|
| 마이페이지 프로필 사진 밑 · GNB 사용자 메뉴 | '메일 미인증' 배지 | '메일 미인증' 배지 (파트너 인증 배지보다 먼저 표시) |
| 내 정보 관리 > 이메일 | '메일 미인증' + [인증 메일 다시 보내기] + 안내 인포박스 | 동일 |
| 파트너 인증 화면 | – | 4절 참고 |
| 인증 안내 팝업 | – | 5절 참고 |

## 3. 분석파트너 인증 상태

| 상태 | 조건 | 컨설턴트 검토 목록 노출 |
|---|---|---|
| 미제출 | 사업자등록증 없음 | 아니오 |
| 검토 대기 | 사업자등록증 있음 + 이메일 미인증 | 아니오 |
| 검토 중 | 사업자등록증 있음 + 이메일 인증 완료 | **예** |
| 반려(재제출 요청) | 컨설턴트가 재제출 요청 | 아니오 (다시 제출하면 '검토 중') |
| 인증 완료 | 컨설턴트가 인증 처리 | – |

상태가 바뀌는 때
1. **사업자등록증 저장**
   - 이메일 인증 완료 → 바로 '검토 중'
   - 이메일 미인증 → '검토 대기'
2. **이메일 인증 완료** → '검토 대기'였다면 자동으로 '검토 중' (파트너가 따로 누르지 않음)
3. **컨설턴트 처리** → '인증 완료' 또는 '반려(재제출 요청)'
4. **반려 후 다시 제출** → '검토 중' (이메일 인증 완료 상태이므로)

## 4. 파트너 인증 화면 (`mypage-verify.html`)

구성: 인증 절차 안내(일러스트 3단계, 안내용) → 인증 상태 인포박스 → 기관 정보(기관명 · 대표자명 · 사업자등록번호 · 주소 · 사업자등록증)

| 상태 | 위쪽 인증 상태 인포박스 | 기관 정보 입력 | 사업자등록증 | 표 아래 인포박스 |
|---|---|---|---|---|
| 미제출 | (경고) 아직 인증되지 않은 분석파트너입니다. | 가능 | 올리기 가능 | 이메일 미인증이면 (경고) "이메일 인증을 완료해야 인증 검토가 시작됩니다…" |
| 검토 대기 | (경고) 이메일 인증 후 인증 검토가 시작됩니다. | 가능 | 변경·삭제 가능 | 없음 |
| 검토 중 | (기본) 인증 검토 중입니다. | 가능 | 변경 불가 (삭제 후 다시 올리면 검토 다시 시작) | 없음 |
| 인증 완료 | (강조) 인증이 완료된 분석파트너입니다. | **보기 전용** | **보기 전용 · 삭제 불가** | (기본) "인증된 기관 정보는 계약에 사용되어 직접 수정할 수 없습니다. 변경이 필요하면 문의하기로 알려 주세요." |

- 인증 완료 후 기관 정보·사업자등록증 변경은 **문의하기**로 접수하고 컨설턴트가 반영합니다. 파트너 동의 없이 컨설턴트가 정보를 바꾸지 않습니다.
- 주소는 직접 입력하지 않고 주소 검색 API로 선택합니다. (프로토타입은 안내 토스트 + 예시 주소)
- 사업자등록번호 형식: `000-00-00000`

## 5. 인증 안내 팝업 (미인증 분석파트너가 [견적서 작성]을 누를 때)

위치: 프로젝트 찾기 목록 · 프로젝트 상세의 [견적서 작성] (구현: `assets/common/site.js`의 `OP.verifyGate`)

- 제목: "파트너 인증을 위한 필수 정보를 등록해주세요"
- 설명: "인증이 완료되면 견적서 작성·제출, 비공개 프로젝트 열람, 프로젝트 매칭·계약을 이용할 수 있습니다."
- 진행률: 필수 3개(이메일 인증 · 파트너 정보 · 사업자등록증 인증) 기준. 팝업에는 0·33·67%만 보이고 100%는 인증 완료(팝업 없음)
- 항목 버튼

| 항목 | 표시 |
|---|---|
| 이메일 인증 | 항상 표시. 완료면 완료(✓), 미인증이면 누를 때 인증 메일 재발송 토스트 |
| 파트너 정보 등록 | 가입 시 완료 → 완료(✓) 표시 |
| 사업자등록증 업로드 | 인증 완료 전에는 항상 활성 → 파트너 인증 화면으로 이동 |
| 제공 분석 서비스 입력(선택) | 항상 활성 → 분석 서비스 정보 화면으로 이동 (진행률 제외) |

## 6. 컨설턴트 쪽 — 분석파트너 관리 (`mypage-partners.html`)

- 메뉴: 마이페이지 > 관리 > 분석파트너 관리 (컨설턴트 전용)
- 목록 탭: **인증 검토**(=검토 중, 기본) · 재제출 요청 · 인증 완료 · 미제출·검토 대기 · 전체
  - '검토 대기'(이메일 미인증)는 인증 검토 탭에 나오지 않습니다.
- 상세: 기관명 · 대표자명 · 사업자등록번호 · 주소 · 담당자 · 이메일(미인증 표시) · 제공 분석 서비스 · 사업자등록증
- 사업자등록증 줄: [보기] (원본 미리보기) · **[인증 완료]** · **[재제출 요청]** — 검토 중일 때만 처리 버튼 노출, 미리보기 창 위쪽에도 같은 버튼
  - [인증 완료]: 확인창 → 인증 처리 → 분석파트너에게 알림
  - [재제출 요청]: 요청 사유 입력(필수) → 분석파트너에게 알림 + 파트너 인증 화면에 사유 표시
  - 클라이언트 사업자등록증 재제출 요청(`mypage-request.html` 의뢰 상세)과 같은 방식입니다.
- 분석파트너가 재제출 요청을 받으면: 파트너 인증 화면 상단에 "사업자등록증을 다시 제출해주세요. · 사유: …" (경고), 사업자등록증 변경 가능 → 새 파일 저장 시 재제출 요청 해제 · '검토 중'으로 다시 목록에 올라옴

## 7. 알림

| 받는 사람 | 시점 | 프로토타입 |
|---|---|---|
| 컨설턴트 | 분석파트너가 '검토 중'에 들어갈 때 (사업자등록증 저장, 이메일 인증 완료, 재제출) | 사이트 알림 구현 (알림 → 분석파트너 관리 상세, 메뉴 N 배지)<br>· 첫 제출·메일 인증 완료: "세움분석센터가 파트너 인증을 요청했습니다. 사업자등록증을 확인해주세요."<br>· 재제출: "세움분석센터가 사업자등록증을 다시 제출했습니다. 확인 후 인증 처리해주세요." |
| 분석파트너 | 인증 완료 / 재제출 요청 (메일 + 사이트 알림) | 사이트 알림 구현 (알림 → 파트너 인증 화면) |

## 8. 분석 서비스 정보 입력 요청 (컨설턴트 → 분석파트너)

- 입력 시점: 회원가입 때는 대표 서비스 1개(서비스·수행 상태 필수, 표준 소요 기간 선택)만 받고, 서비스별 세부 항목은 가입 후 마이페이지 [분석 서비스 정보]에서 입력합니다. 가입 때 받은 대표 서비스가 이 화면의 첫 번째 서비스가 됩니다.
- **요청 기준 (견적서 확인 목록·AI 매칭 공통):** 해당 의뢰 서비스의 세부 항목을 입력하지 않은 분석파트너. 화면 문구는 상황에 따라 '분석 서비스 정보 미입력'(서비스 없음) / '이 의뢰 서비스 미등록'(다른 서비스만 등록) / '세부 항목 미입력'(서비스만 등록)
  - 가입 때 대표 서비스를 필수로 받으므로 '서비스가 하나도 없는 분석파트너'는 거의 없습니다. 그래서 '서비스 1개 이상이면 입력됨'으로 보지 않습니다.
  - 두 화면의 요청은 하나입니다. 한 곳에서 요청하면 다른 곳에도 '입력 요청함'으로 보이고, 알림은 한 번만 갑니다.
- 컨설턴트 화면: 프로젝트 관리 > 의뢰 상세 > 견적서 확인 목록에서, 위 기준에 해당하는 파트너 줄에 '(사유) · [입력 요청]'이 보입니다. 누르면 확인 모달(요청하기/취소)이 뜨고, 요청하면 '입력 요청함'으로 바뀝니다.
- [✦ AI 분석파트너 매칭] 팝업의 '분석 서비스 정보 없음' 묶음에서도 같은 [입력 요청]을 보낼 수 있습니다(9절).
- 분석파트너가 받는 것: 사이트 알림 "분석 서비스 정보를 입력해주세요." (→ 회원정보 > 분석 서비스 정보), 그 화면 위쪽 경고 인포박스(서비스를 저장하면 사라짐)
- 입력 항목: 서비스를 고르면 R&D 사례작성 v5의 공급자 입력 항목(provider_fields)이 그 서비스에 맞게 펼쳐집니다. 데이터는 `assets/common/svc-spec.js` (v5 파일의 SPEC에서 그대로 옮김, 기타 분석은 v5 파일이 없어 수행 상태·소요 기간만).
  - 다른 항목 선택에 따라 나오는 조건부 항목(when), 기타 선택 시 상세 필수, 보이는 필수 항목 확인, 최소 ≤ 최대 소요일
  - 체크하지 않은 항목 = 미지원 (v5 기준. 화면에는 따로 표시하지 않음)
  - 같은 서비스를 여러 번 등록하면 '수행 조건 1, 2…'로 나뉨 (함께 제공할 수 없는 조건 분리)
- **안내만 합니다.** 미입력이어도 견적 전달·다음 견적 작성은 막지 않습니다.

## 9. AI 분석파트너 매칭 (컨설턴트 전용)

- 위치: 의뢰 상세 > 견적서 확인 머리의 **[✦ AI 분석파트너 매칭]**. 버튼을 눌러야 매칭이 실행됩니다(처음 열 때 비교 → 결과). 실행한 뒤에는 버튼 옆에 '날짜 시각 매칭 · 추천 n곳'이 보이고, 팝업의 [다시 비교]로 다시 실행합니다.
- 순위·점수(%)는 없습니다. 인증된 분석파트너 전체를 의뢰 내용과 분석 서비스 정보(v5 provider_fields)로 비교합니다. 항목별 칩: 충족(초록) · 미지원(빨강) · 확인 필요(회색)
- 팝업은 탭 3개로 나눕니다.
  - **추천**: 정보로 비교된 곳. 조건 충족 · 확인 필요(미리 체크) · 일부 미지원(접어 둠)
  - **정보 부족**: 분석 서비스 정보 없음 · 이 서비스 미등록. [입력 요청] 가능, 체크는 할 수 있지만 미리 체크하지 않음
  - **참여 중**: 견적제안을 받았거나 직접 신청한 곳. 체크 없음, 실제 진행 상태(견적제안·직접 신청 + 작성 대기·제출 완료 등)와 매칭 결과 배지
- 파트너 줄에 함께 보이는 정보
  - 수행 이력: '단백체 수행 24건 · 과거 견적서 17건 · 즉시 수행 가능 · 25~35 영업일' (수행 상태·소요 영업일은 분석 서비스 정보, 없으면 평균 소요 기간)
  - 단계: v5 후보 필터 순서(`svc-spec.js`의 stages)에서 처음 미지원·정보 없음이 나온 단계. 예: '3.2 시료 종류 단계에서 미지원'
  - 확인 필요 사항: 후보를 줄이지 않고 컨설턴트가 확인할 값 (목록 밖 값, Library 유형·시퀀싱 방식·시료 상태)
- **전문가 수행 판단 (v5 judgment)**: 파트너마다 [수행 판단]으로 기록. 컨설턴트만 봄
  - 수행 판단: 수행 가능 / 수행 불가 / 정보 부족으로 판단 불가 / 판단 보류
  - 판단 이유·근거(필수, 보류면 보류 사유), 수행 불가 범위(수행 불가일 때 필수), 판단에 부족한 정보(정보 부족일 때 필수), 분석파트너에게 확인할 질문(선택)
  - 저장하면 줄에 판단 배지와 요약이 보임. 의뢰·파트너별로 저장(프로토타입: localStorage op.judge)
- 미인증 분석파트너는 견적을 낼 수 없어 목록에서 빼고 "미인증 분석파트너 n곳은 … 제외했습니다."만 보여 줍니다.
- 발송해도 팝업은 닫히지 않습니다. 보낸 곳은 '참여 중' 탭으로 옮겨집니다.
- **매칭은 추천일 뿐 견적 자격이 아닙니다.** 인증된 분석파트너는 추천·발송과 상관없이 볼 수 있는 프로젝트에 직접 견적서를 낼 수 있습니다(직접 신청). 그래서 '이 서비스 미등록'이나 '분석 서비스 정보 없음'인 파트너도 견적을 제출할 수 있습니다.
- 매칭 결과는 분석파트너·클라이언트에게 보이지 않습니다.

## 10. 미정 항목

- 재제출 요청 사유를 정해진 항목에서 고를지, 직접 입력만 할지
- '검토 대기'로 오래 남은 계정에 리마인드 메일을 보낼지, 보낸다면 주기
- 인증 후 문의로 받은 기관 정보 변경을 컨설턴트가 반영할 때 재검토 기록을 남길지
- 입력 요청 후에도 오래 입력하지 않으면 다시 알릴지
- 매칭 팝업에서 '확인 필요' 파트너를 미리 체크할지

## 11. 프로토타입 데모 조작

GNB 사용자 메뉴의 '화면 전환 (데모)'에서 아래를 바꿔 각 상태를 볼 수 있습니다.
- 인증 표시 (데모): 분석파트너 인증 / 미인증
- 메일 인증 (데모): 완료 / 미완료
- 분석 서비스 정보 (데모, 분석파트너): 입력 / 미입력
