# 회원정보 변경 사항 (회원가입 · 아이디 찾기 · 마이페이지 회원정보)

2026-10-21 기준. 개발팀 문의(1~7번) 회신 이후 프로토타입에 반영한 내용입니다.
기본 원칙: **로그인·회원가입에서 받는 필수 항목은 마이페이지에도 똑같이 들어갑니다.**

프로토타입: https://2updown.github.io/omicspharm-design/
(데모 계정 `client@` · `partner@` · `admin@omicspharm.test`)

---

## 1. 공통

| 항목 | 규칙 |
|---|---|
| 비밀번호 | 8~20자, 영문·숫자·특수문자 각 1자 이상 (대·소문자 구분 조건 없음). 회원가입·비밀번호 재설정·내 정보 관리 모두 같음 |
| 휴대폰 번호 | [국가번호 ▾] + 입력란 한 칸, 입력하면 하이픈 자동 (010-0000-0000). 한국(+82, 기본값)·일본(+81), 국가번호에 따라 안내 문구 010 / 090 (2026-10-22 외주사 미팅 확정) |
| 휴대폰 중복 | 같은 번호는 한 계정만. 휴대폰 인증 없이 번호 중복만 확인, 중복이면 입력란 아래 "이미 사용중인 연락처입니다." (회원가입·내 정보 관리 모두) |
| 사업자등록번호 | 한국 10자리 `000-00-00000`, 입력 시 하이픈 자동. 선택 항목이지만 입력했다면 10자리가 아니면 "사업자등록번호 10자리를 입력해주세요." |
| 소속 이름 | 모든 화면에서 **소속(기관·회사)** |
| 표준 소요 기간 | 모든 화면에서 **영업일**, 1~365 |

## 2. 회원가입 (`signup-form.html`)

**기본정보** — 이름 → 닉네임 → 휴대폰 번호 → 소속(기관·회사) → 부서 → 국가 (모두 필수)
- 국가를 South Korea / Japan으로 고르면 휴대폰 국가번호가 +82 / +81로 자동 변경
- 닉네임·국가는 가입 시 저장되어 내 정보 관리에 그대로 보임

**추가 정보 (분석파트너) — 분석 서비스**
- 서비스 **복수 선택** (1개 이상 필수), 수행 상태(필수), 표준 소요 기간(선택, 기본 7~14 영업일)
- 수행 상태·소요 기간은 고른 서비스에 같은 값으로 들어감
- 안내 문구: "제공하는 서비스를 선택하면 관련 프로젝트 추천에 활용됩니다. / 서비스별 상세 정보는 가입 후 마이페이지에서 언제든 입력·수정할 수 있습니다."

**추가 정보 — 기관 정보 (클라이언트·분석파트너 공통, 모두 선택)**
- 대표자명, 사업자등록번호, 주소(검색), 사업자등록증
- 클라이언트가 입력한 값도 저장 (견적서·계약서의 클라이언트 기관 정보로 사용)

**회원탈퇴 후 재가입** — 탈퇴한 이메일은 **7일** 동안 재가입 불가. 이메일 입력란 아래 "탈퇴한 이메일은 7일이 지나야 다시 가입할 수 있습니다."

## 3. 아이디 찾기 (`find-id.html`)
- 이름 + 휴대폰 번호(+82/+81). 같은 번호는 한 계정만이므로 결과는 1건
- 가입 이메일 마스킹 표시 (앞 2자 + *** + @도메인)

## 4. 마이페이지 > 내 정보 관리 (`mypage-account.html`)

진입 시 비밀번호 재확인. 틀리면 입력란 아래 "현재 비밀번호가 일치하지 않습니다."

**기본 정보** (가입 순서와 같음)

|---|---|---|
| 프로필 사진 | - | JPG·PNG 10MB 이하 |
| 이메일(아이디) | - | 보기 전용 |
| 회원 유형 | - | 보기 전용 |

**기관 정보 (클라이언트만, 별도 섹션 · 별도 [저장하기])**
- 대표자명, 사업자등록번호, 주소, 사업자등록증 (모두 선택)
- 사업자등록증이 OmicsPharm 확인 완료되면 네 항목 모두 보기 전용 + 안내 "OmicsPharm 확인이 완료된 기관 정보와 사업자등록증은 프로젝트 등록·계약에 사용되어 직접 수정할 수 없습니다. 변경이 필요하면 문의하기로 알려 주세요."
- 분석파트너의 기관 정보는 [파트너 인증] 화면에서

**삭제한 것** — 알림 설정 (기존 사이트에 없고 가입 때도 받지 않음)

## 5. 마이페이지 > 파트너 인증 (`mypage-verify.html`, 분석파트너)
- '기관명' → **소속(기관·회사)** (보기 전용)
- 인증 요청에는 대표자명·사업자등록번호·주소·사업자등록증 모두 필수 (가입 때는 선택)

## 6. 마이페이지 > 분석 서비스 정보 (`mypage-service.html`, 분석파트너)

- 가입 때 고른 서비스가 카드로 하나씩, 처음엔 **모두 접힌 상태** (서비스명 + 요약 `수행 상태 · 분석 유형 · 소요 기간`)
- '등록된 서비스 없음' 화면은 없음. 서비스는 1개 이상 필수 → 마지막 서비스 삭제 시 토스트 "분석 서비스는 1개 이상 등록해야 합니다. 다른 서비스를 먼저 추가해 주세요."
- **저장은 서비스(카드)마다** — 펼친 카드 맨 아래 [저장], 페이지 전체 저장 버튼 없음
  - 바뀐 게 없으면 [저장] 비활성
  - 세부 항목을 하나도 입력하지 않은 카드: 서비스 + 수행 상태만으로 저장 가능, 제목 옆 '세부 항목 미입력' 칩
  - 세부 항목을 하나라도 입력한 카드: 그 카드의 필수(*) 항목을 모두 채워야 저장
  - 새로 추가·복사한 카드는 '저장 전' 칩, [저장]을 눌러야 등록
- **확인 모달**
  - 세부 항목을 입력한 뒤 다른 서비스를 누르면: "서비스를 변경할까요? / 입력한 세부 항목이 모두 초기화됩니다." [취소][변경] (입력한 게 없으면 바로 변경)
  - 저장된 서비스 삭제: "'서비스 N · ○○' 항목을 삭제할까요?" → 바로 반영 (저장 전 카드는 모달 없이 삭제)
  - 저장하지 않고 다른 페이지로 이동: "작성을 취소하시겠습니까? / 지금 나가면 저장되지 않은 내용이 사라집니다." [취소][나가기] (새로고침·창 닫기는 브라우저 기본 경고)
- **입력 요청 안내 박스**: 컨설턴트가 입력을 요청했고 세부 항목을 채우지 않은 서비스가 있으면 상단 경고 "OmicsPharm이 분석 서비스 정보 입력을 요청했습니다. 서비스별 세부 항목을 입력해 주세요."
- 입력 요청 기준·화면 공유는 `docs/partner-verification.md` 8절

## 7. 회원탈퇴 (`mypage-leave.html`)
- 안내: "탈퇴 후 7일 동안은 같은 이메일로 다시 가입할 수 없습니다."
