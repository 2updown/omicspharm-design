# 프로토타입 변경 사항 (2026-11-12 ~ 11-13)

모바일 검수(375px 기준, 비회원·클라이언트·분석파트너·컨설턴트)에서 고친 내용과, 그 과정에서 PC에도 함께 바뀐 내용입니다.
프로토타입: https://2updown.github.io/omicspharm-design/

표시: **[모바일]** 640px 이하만, **[공통]** PC와 모바일 모두

---

## 1. 공통 컴포넌트

- **[공통] 마이페이지 줄바꿈**: 한글이 단어 중간에서 끊기지 않게 마이페이지 전체 `word-break:keep-all; overflow-wrap:break-word`. 상담 대화 말풍선, 챗봇 말풍선도 같게.
- **[공통] 금액 표기**: 통화 기호와 숫자 사이를 줄바꿈 안 되는 공백으로 (₩ 와 139,000이 다른 줄로 갈리지 않게).
- **[공통] 정보 줄 구분선**: 여러 항목을 세로선으로 나눈 정보 줄은 항목 단위로만 줄바꿈하고, 줄 앞뒤에 구분선이 남지 않게 (결과보고서 머리, 상담 상세 정보 줄, AI 매칭 카드 실적 줄, 프로젝트 카드 meta).
- **[공통] 확인 모달 버튼 색**: 되돌릴 수 없는 동작(삭제, 탈퇴, 지우기, 초기화, 나가기)만 빨강, 그 밖(승인, 변경, 저장 등)은 초록. hover도 같은 계열(빨강 → 진한 빨강, 초록 → 진한 초록).
  - 고친 곳: 클라이언트 프로젝트 삭제 모달 hover가 초록으로 바뀌던 것, 컨설턴트 프로젝트 삭제 모달이 초록이던 것, 분석 서비스 변경 확인이 빨강이던 것.
- **[모바일] 페이지네이션**: 버튼 32px(아이콘 16, 글자 14), 한 줄 고정. 버튼 9개(처음, 이전, 숫자 5, 다음, 끝)도 한 줄에 들어감.
- **[모바일] 문서 미리보기(견적서, 견적서 미리보기, 계약서)**: 문서 폭 794px(A4) 그대로 두고 화면 폭에 맞춰 비율대로 축소. 표 칸이 찌그러지지 않음. 인쇄/PDF는 그대로.
- **[공통] textarea**: 크기 조절 끔 (`resize:none`).

## 2. 마이페이지 구조 (모바일)

- **상단 '‹ 마이페이지' + 메뉴 탭**: 목록 화면에서만 표시. 스크롤하면 같이 올라감(고정 아님).
- **상세 화면** (프로젝트 상세, 견적서 작성, 상담·문의 상세, 클라이언트·분석파트너 관리 상세)
  - 메뉴 탭, 큰 메뉴 제목, 본문 제목 앞 [‹] 숨김.
  - 맨 위 줄은 '‹ 상위 목록 이름'(예: ‹ 프로젝트 관리, ‹ 상담내역) 하나만. 누르면 원래 왔던 화면, 링크로 바로 들어왔으면 목록.
- **AI Agent**: 모바일(960px 이하)에서 직접 들어오면 토스트 안내 후 마이페이지로.
- **관리 표(클라이언트·분석파트너 관리)**: 가로 스크롤 유지, 좌우 끝에 흰색 페이드(40px)로 넘길 수 있음을 표시.
