# Workspace CTA 애니메이션 기록

2026-11-10 피드백으로 메인 하단 CTA를 예전 분석 의뢰 CTA(Figma 2562:30110)로 되돌렸다. 그 전까지 메인에 있던 Workspace CTA의 효과를 다시 쓸 수 있게 남겨 둔다.

## 어디에 남아 있나
- 워크스페이스 페이지 하단 CTA (`assets/workspace/ws.css`의 `.wcta`, `assets/workspace/ws.js`의 spotlight 루프)는 그대로 쓰고 있다.
- 워크스페이스 히어로(`.ws-hero2`)도 같은 배경과 점 효과를 쓴다 (마우스 따라가기만 없음).
- 메인 버전 원본: 커밋 `9f109a05`의 `index.html` (`.ws-cta`, `.ws-dots`, `.ws-spot`).

## 효과 구성
1. **배경**: 짙은 잉크 teal 그라디언트 `linear-gradient(160deg, #0a2a27, #04201d 55%, #031a18)`.
2. **아래쪽 빛**: 박스 아래에 흐린 타원 두 개.
   - 넓은 빛: teal → 민트 → 블루 그라디언트, blur 120px, 투명도 .6
   - 가운데 빛: #c9fff3, blur 70px, 투명도 .45
3. **점 패턴** (`.ws-dots`): 12px 간격의 옅은 흰 점 (투명도 .09).
4. **점 스포트라이트** (`.ws-spot`): 민트색 점 레이어에 지름 220px 원형 mask를 씌워서, 원 안의 점만 밝게 보인다.
   - 마우스가 박스 위에 있으면 원이 마우스를 따라간다.
   - 마우스가 없으면 원이 9초 주기로 좌우로(위아래로 살짝 흔들리며) 지나간다.
   - 화면 밖에 있으면 멈추고, 스크롤해서 들어오면 다시 시작한다.
   - 움직임 줄이기 설정(prefers-reduced-motion)에서는 스포트라이트를 끈다.
5. **영문 소제목**: teal → 블루 그라디언트 글자.
6. **버튼**: 흰 버튼(teal 글자) + 반투명 흰 고스트 버튼.
