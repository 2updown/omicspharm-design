# 프로젝트 상세 화면 공통 레이아웃

최종 수정 2026-10-27

프로젝트 관리의 상세 화면(클라이언트·분석파트너·컨설턴트)이 모두 같은 순서와 모양을 쓰도록 정리한 규칙입니다. 배지 색은 [배지 색 규칙 · 서비스 상태값 정리](status-badges.md)를 따릅니다.

## 1. 대상 화면

| 역할 | 화면 |
|---|---|
| 클라이언트 | 프로젝트 관리 > 프로젝트 상세 |
| 분석파트너 | 프로젝트 관리 > 견적서 (견적 단계) · 프로젝트 상세 (계약 이후) |
| 컨설턴트 | 프로젝트 관리 > 의뢰 상세 |

## 2. 화면 순서

모든 상세 화면은 위에서 아래로 한 페이지에 이어서 보여 줍니다. 탭으로 나누지 않습니다.

1. **제목 영역**
2. **진행 단계**
3. **할 일 안내 박스**
4. **단계별 내용** (지금 단계와 가까운 것이 위)
5. **의뢰 내용** (접어 둠)
6. **관리 영역** (컨설턴트만: 수정·삭제)

## 3. 제목 영역

- 첫 줄: 배지 두 개(분석 서비스 outline + 프로젝트 단계 tertiary)와 오른쪽 끝의 날짜·프로젝트 번호
- 둘째 줄: [뒤로] + 프로젝트명, 오른쪽에 기간 정보와 [문의하기]
- 견적서 상태(임시저장, 수정 요청 등)는 배지로 붙이지 않고 할 일 안내 박스에서 보여 줍니다.

| 역할 | 첫 줄 오른쪽 | 둘째 줄 오른쪽 |
|---|---|---|
| 클라이언트 | 등록일 · 프로젝트 번호 | [문의하기] |
| 분석파트너 (견적서) | 견적 요청일 또는 견적 신청일 | 견적 마감일 + D-숫자 · [문의하기] |
| 분석파트너 (계약 이후) | 계약일 · 프로젝트 번호 | 납기일 + D-숫자 · [문의하기] |
| 컨설턴트 | 접수일 · 프로젝트 번호 | 클라이언트(기관 · 담당자) · [문의하기] |

## 4. 진행 단계

가로 막대로 지난 단계(연한 청록) · 지금 단계(청록, 굵은 글씨) · 남은 단계(회색)를 보여 줍니다. 단계 이름은 프로젝트 상태값과 같습니다.

| 역할 | 단계 |
|---|---|
| 클라이언트 (7) | 의뢰접수 → 의뢰승인 → 견적 확인 → 계약 진행 중 → 분석 진행 중 → 보고서 검토 → 프로젝트 완료 |
| 분석파트너 (7) | 견적 요청 → 견적 제출 → 계약 진행 중 → 분석 진행 중 → 보고서 등록 → 보고서 검토 → 프로젝트 완료 |
| 컨설턴트 (8) | 의뢰접수 → 의뢰확인 → 견적 협의 → 계약 진행 중 → 분석 진행 중 → 보고서 등록 → 보고서 검토 → 프로젝트 완료 |

- 분석파트너의 견적서 화면과 프로젝트 상세는 같은 7단계를 씁니다.
- 미선정·거절, 삭제는 단계가 아니므로 지금 단계 표시 없이 보여 줍니다.
- 모바일(640px 이하)에서는 한 줄에 3단계씩 줄을 바꿉니다.

## 5. 할 일 안내 박스

진행 단계 바로 아래에 지금 무엇을 해야 하는지 한 문장(굵게)과 설명을 보여 줍니다. 처리 버튼이 있으면 박스 오른쪽에 둡니다(모바일에서는 아래로).

| 색 | 쓰는 때 | 예 |
|---|---|---|
| 주황 | 화면을 보는 사람이 처리해야 함 | 의뢰서가 접수되었습니다. 확인 후 승인처리 해주세요. / 분석이 진행 중입니다 (결과를 올려 주세요) |
| 회색 | 다른 사람의 처리를 기다리는 중 | 클라이언트가 견적서를 확인하고 있습니다. / 등록한 결과를 OmicsPharm이 검토하고 있습니다 |
| 연한 청록 (기본) | 안내 · 완료 | 프로젝트가 완료되었습니다. |

## 6. 단계별 내용 순서

지금 단계와 가까운 내용을 위에 둡니다. 아직 없는 내용(예: 계약 전 결과보고서)은 보이지 않습니다.

| 역할 | 순서 |
|---|---|
| 클라이언트 | 결과보고서 → 계약 정보 → 견적서 → 의뢰 내용 |
| 분석파트너 (계약 이후) | 결과보고서 → 계약서 → 프로젝트 정보 |
| 컨설턴트 | 결과보고서 → 계약 정보 → 견적서 확인 → 사업자등록증 → 의뢰 내용 → 의뢰 전 상담 → 관리(수정·삭제) |

- 컨설턴트의 사업자등록증은 의뢰 승인 전에는 할 일 안내 박스 바로 아래에 둡니다.

## 7. 예외

- **분석파트너 견적서 화면:** 제목 영역 · 진행 단계 · 할 일 안내 박스는 다른 상세와 같고, 그 아래만 [의뢰내용] / [견적서 작성] 탭으로 나눕니다. 견적서 입력 표가 길어 의뢰 내용과 한 페이지에 두면 작성하기 불편하기 때문입니다.
