How Enterprise Works도입은 센터·회사 단위로, 운영은 연구실 단위로.

01도입 단위 결정·환경 구축

센터·병원 또는 연구소·회사 단위를 정하고, 전용 클라우드나 기관 내부에 환경을 구축합니다.

02팀 Workspace 생성·배정

관리자가 콘솔에서 진료과·연구소·부서별 Workspace를 만들고 구성원을 배정합니다.

03팀별 Agent 구성

각 팀의 연구 목적에 맞는 AI Agent를 설정하고, 활용 데이터와 접근 권한을 정합니다.

04기관 지식으로 확장

팀 지식은 분리해 관리하고, 기관 공통 지식은 정책에 따라 여러 팀이 함께 활용합니다.

Built for Organizations기관 전체를 위한 관리 기능.

팀 Workspace 생성·관리

관리자가 필요한 팀에 Workspace를 직접 만들고, 프로젝트가 끝나면 보관하거나 정리합니다.

팀 간 데이터 분리

같은 기관 안에서도 팀별 데이터와 Agent 기록은 서로 보이지 않습니다. 공유는 승인된 범위에서만 이뤄집니다.

기관 공통 지식 관리

SOP, 가이드라인, 공통 문헌처럼 모든 팀이 참고할 자료는 한 번 등록해 여러 Workspace에서 활용합니다.

계정·권한 정책

기관 계정과 연동하고, 역할별 접근 권한과 외부 AI 사용 범위를 기관 단위로 정합니다.

사용량·접근 기록

팀별 사용량과 Agent 활용 현황, 데이터 접근 기록을 관리자가 한곳에서 확인합니다.

기존 시스템 연계

LIMS, ELN, 문서관리 시스템 등 기관이 사용하는 시스템과의 연계 범위를 함께 설계합니다.

관리 기능과 시스템 연계의 구체적인 범위는 도입 환경과 별도 협의에 따라 정합니다.
